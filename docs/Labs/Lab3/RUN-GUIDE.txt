2. TỰ CHẠY LẠI (PowerShell, cần Node.js 18+, có mạng để npm ci)
======================================================================
Mở thư mục mã nguồn ứng dụng phiên bản 1.0.0 (thư mục có file package.json) và cài thư viện:

  cd <thư mục mã nguồn ứng dụng>
  npm ci

Chép 2 file test vào chỗ Vitest của ứng dụng tự tìm (tests/unit/):

  New-Item -ItemType Directory -Force tests\unit\lab3
  Copy-Item <thư mục Lab3>\tests\*.test.ts tests\unit\lab3\

Chạy test, xem từng UTCID:

  npx vitest run tests/unit/lab3 --reporter=verbose

Kết quả đúng: 10 dòng có dấu ✓ và dòng "Tests  10 passed (10)".

Tạo lại báo cáo HTML (cần gói @vitest/ui cùng phiên bản với Vitest; --no-save để không sửa package.json):

  npm i -D --no-save @vitest/ui@2.1.9
  npx vitest run tests/unit/lab3 --reporter=verbose --reporter=html --outputFile.html=lab3-report/index.html

Dọn dẹp khi xong (xoá các file đã chép và báo cáo vừa tạo trong thư mục mã nguồn):

  Remove-Item -Recurse -Force tests\unit\lab3, lab3-report -ErrorAction SilentlyContinue

======================================================================
3. XEM BÁO CÁO HTML
======================================================================
Bấm đúp index.html sẽ thấy trang trống, vì báo cáo phải mở qua một server web. Cách mở:

- Trong thư mục mã nguồn ứng dụng ở trên:  npx vite preview --outDir <thư mục html-report>
  rồi mở địa chỉ hiện ra (ví dụ http://localhost:4173).
- Hoặc nếu máy có Python:  cd results\html-report  rồi  python -m http.server 8000
  và mở http://localhost:8000.
- Xem nhanh không cần chạy gì: results\vitest-html-report.png.
